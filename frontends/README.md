# 🎨 Frontends individuels

Chaque membre a **son** dossier `frontend-<pseudo-github>/` (créé automatiquement à la création du dépôt).
Technologie libre : Streamlit (le plus rapide, comme SmartCity), Next.js / React, Astro, Vue…

Votre `frontend-<pseudo>/README.md` doit indiquer :
1. la technologie choisie ;
2. comment l'installer et le lancer (commandes exactes) ;
3. les routes de `API_ROUTES.md` consommées par chaque page.

Pages attendues (voir la grille d'évaluation) :
- **Profil & Parcours** (timeline) ;
- **Galerie & détail des projets** ;
- **Graphe de compétences** et **projets similaires** (Neo4j).
